# SmartBus – Intelligent Bus Monitoring System

## Overview
SmartBus is an intelligent transportation system that combines computer vision and AI to improve bus safety and passenger monitoring.

## Main Features

### 1. Passenger Counting
- Detects and counts bus passengers using a camera.
- Provides automated passenger monitoring.

### 2. Driver Monitoring
- Seatbelt detection.
- Mobile phone usage detection.
- Smoking detection.
- Drowsiness detection.
- Camera obstruction detection.
- Voice alerts for unsafe driving behaviors.

## Technologies Used
- Python
- OpenCV
- YOLO
- MediaPipe
- Computer Vision
- Machine Learning

## Project Structure
The project includes separate modules for passenger counting, driver monitoring, object detection, and alert systems.

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Running the Project

Run the appropriate main Python script for each system.

## Note
A working camera is required to run the real-time monitoring features.
